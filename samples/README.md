# Samples

A curated catalog of samples that build on the [AI Gateway tier in Azure API Management](https://aka.ms/aigateway/docs). This folder catalogs samples that live in their own repositories; it does not host sample code.

| Sample | Language | Description |
| ------ | -------- | ----------- |
| Foundry AI Gateway E2E | [Python](https://github.com/coreai-microsoft/simple-foundry-hosted-agent-python-aigateway) / [.NET (C#)](https://github.com/coreai-microsoft/simple-foundry-hosted-agent-dotnet-aigateway) | A Daily Digest Agent deployed as a Foundry Hosted Agent whose model and GitHub MCP traffic is routed through AI Gateway. |
| IaC only | [Bicep](https://github.com/coreai-microsoft/simple-foundry-hosted-agent-python-aigateway/tree/main/infra/ai-gateway) | Infrastructure as code for the building blocks: [AI Gateway](https://github.com/coreai-microsoft/simple-foundry-hosted-agent-python-aigateway/tree/main/infra/ai-gateway), [Foundry Models](https://github.com/coreai-microsoft/simple-foundry-hosted-agent-python-aigateway/tree/main/infra/foundry-models), and [Foundry Hosted Agent](https://github.com/coreai-microsoft/simple-foundry-hosted-agent-python-aigateway/tree/main/infra/foundry-agents). |
