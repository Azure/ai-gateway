# Samples

A curated catalog of samples that build on the [AI Gateway tier in Azure API Management](https://aka.ms/aigateway/docs). This folder catalogs samples that live in their own repositories; it does not host sample code.

| Sample | Language | Description |
| ------ | -------- | ----------- |
| Foundry AI Gateway E2E | [Python](https://aka.ms/foundry-aigateway-python) / [.NET (C#)](https://aka.ms/foundry-aigateway-dotnet) | A Daily Digest Agent deployed as a Foundry Hosted Agent whose model and GitHub MCP traffic is routed through AI Gateway. |
| IaC only | [Bicep](https://aka.ms/foundry-aigateway-python/tree/main/infra/ai-gateway) | Infrastructure as code for provisioning infrastructure using Bicep, scripts, or azd. Direct links to the building blocks: [AI Gateway](https://aka.ms/foundry-aigateway-python/tree/main/infra/ai-gateway), [Foundry Models](https://aka.ms/foundry-aigateway-python/tree/main/infra/foundry-models), and [Foundry Hosted Agent](https://aka.ms/foundry-aigateway-python/tree/main/infra/foundry-agents). |
