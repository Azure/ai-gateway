Your first model call in five minutes

In the AI Gateway portal, with a few Azure CLI commands in Cloud Shell, or with one azd up, you create a gateway, publish a Microsoft Foundry model behind an alias, and create a runtime key. Then you make your first call through the gateway, the way an app does: with the alias and the key.

Governance & cost

Throttle tokens per caller with token limits

Cap how many tokens each app, agent, or user can consume per minute, hour, or day, and watch the gateway answer with 429 and Retry-After before your backend capacity runs out.

Governance & cost

Enforce cost budgets with per-caller overrides

Give every app, agent, and user a dollar budget per hour, day, or month, raise or lower it for specific API keys and Microsoft Entra identities, and watch the gateway answer 403 LlmCostQuotaExceeded once a caller's estimated spend runs out.

Security & identity

Go keyless with Microsoft Entra ID and RBAC

Replace shared gateway API keys with Microsoft Entra ID tokens. Grant users, groups, apps, and managed identities an AI Gateway data-plane role at the gateway, a model alias, or an MCP server, then call models from the playground, curl, Python, TypeScript, and C# with no secret in code.

Intermediate 35 min
16
Agents

Deploy a Foundry hosted agent behind AI Gateway

Deploy your own Microsoft Agent Framework agent to Foundry Hosted Agents with azd. The agent has no model deployment and no direct tool access, so its model calls and its Microsoft Learn MCP calls go through AI Gateway with a dedicated key. Run it locally, invoke it in Foundry, and cap its tokens without changing its code.

Intermediate 40 min
